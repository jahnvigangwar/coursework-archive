# IBM Developer Skills Network exercises

A small set of course exercises grouped from two IBM Developer Skills Network repositories. These are learning examples, not standalone portfolio projects.

## Exercises

- `github-introduction/simple-interest.sh` — Shell-based simple interest calculator.
- `github-introduction/compound_interest.py` — Python compound growth calculator. The function returns the accumulated amount.
- `css-circle/circle.html` and `css-circle/style.css` — Basic HTML and CSS circle exercise.

## Run

- Open `css-circle/circle.html` in a browser.
- Run the shell exercise with `bash github-introduction/simple-interest.sh`.
- Run the Python exercise with `python3 github-introduction/compound_interest.py`.
