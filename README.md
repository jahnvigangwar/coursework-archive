## How to use this archive

Each project folder has a short README with its original repository link and context. This archive preserves selected source files and notebooks; it does not import each repository's Git history.

To keep the collection small and safe to browse, this snapshot omits local secrets and environment files, local databases, virtual environments, caches, generated outputs, dependency vendor folders, course PDFs and certificates, datasets, and sample audio. Notebook outputs have been cleared. Original attribution and license files are preserved when present. Check each source link for its earlier tree and full history.

There is no shared setup or test command. These are independent learning projects with different runtimes and dependencies; inspect the project folder before running code.
