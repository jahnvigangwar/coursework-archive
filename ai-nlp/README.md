# AI and NLP projects

This section groups AI and machine-learning coursework, two text-focused course exercises, and an attributed team hackathon project. These are archived learning projects; their presence here does not imply that every project is complete or production ready.

## Text and language projects

- [Extractive text summarizer](online-courses/extractive-text-summarizer/) — An NLTK frequency-based sentence scoring exercise. The course input text is not included.
- [Document question answering](online-courses/document-question-answering/) — A course exercise that ranks sentences for who/when/where questions using TF-IDF features. The course input text is not included.
- [NLP course labs](college-projects/nlp-course-labs/) — Tokenization, lexical resources, and neural-network coursework.
- [Character masquerade NLP project](college-projects/character-masquerade-nlp-project/) — A team academic project; individual contributions and evaluation need to be documented before presenting it as a personal project.
